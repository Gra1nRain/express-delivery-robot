# 快递速达小车比赛项目

这是“2026 第六届智能无人系统应用挑战赛—快递速达”小车的新项目骨架。

## 当前边界

- 本目录是新比赛项目，不复制旧 demo。
- 电脑端是 Git 的唯一管理位置；小车只接收可运行代码，不同步 `.git/`、`build/`、`install/`、`log/` 和录包。
- 实验室临时路线与正式比赛路线通过 profile 和 route 配置区分，状态机不写死物理摆放顺序。
- 规划控制主链路按 `global_path -> optimized_trajectory -> body_cmd -> safe chassis command` 分层。
- 避障组只通过 `config/avoidance/` 和约定接口接入，主控保留安全停车兜底。

## 目录说明

```text
competition_car/
├─ src/                 ROS2 功能包
├─ config/              场地 profile、路线、规划、控制和安全参数
├─ maps/                实验室/正式场地点云、栅格和语义地图
├─ launch/              总启动入口和分模块启动文件
├─ scripts/             构建、启动、录包和检查脚本
├─ tests/               单元、接口、离线规划和全流程测试
├─ recordings/          本地测试产物，不进入 Git 或自动同步
└─ docs/                项目架构、接口契约和验收记录
```

## 推荐工作方式

1. 在电脑端修改本目录并进行 Git commit。
2. 自动同步只发送源代码、配置和启动文件到小车的独立工作区。
3. 通过 `ssh ranger-mini` 在小车上构建、运行和读取日志。
4. 稳定版本才进入下一阶段，不在现场重写主状态机、接口协议或主算法。

## 依据

本骨架依据当前目录中的总体方案、技术实现方案、十天冲刺计划和比赛规则第一版创建。规则、方案和当前实现之间存在的差异，必须在后续记录中标记为“事实、经验、建议”或“未验证”。
